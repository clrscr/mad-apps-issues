## 🐛 Reporting Issues

### Before Reporting
1. 🔍 **Search existing issues** to avoid duplicates
2. 📋 **Use the appropriate template** for your issue type
3. 📸 **Include screenshots** when possible
4. 🔄 **Provide reproduction steps** for bugs

### Issue Types
- **🐛 Bug Report**: Something isn't working correctly
- **✨ Feature Request**: New functionality or improvements
- **🌐 Web Platform Issue**: Specific to MadHub web platform
- **🖥️ Desktop App Issue**: Specific to desktop applications
- **📚 Documentation Issue**: Problems with docs or guides

### Labels Overview
Issues are automatically labeled based on content:

#### Components
- `component/madcore` - Core GUI framework
- `component/maditemmaker` - RPG Item Editor
- `component/madquestmaker` - Quest Creation Tool
- `component/theme-editor` - Theme Editor
- `component/story-engine` - Story Generator
- `component/terminal-kingpin` - RPG Game
- `component/madhub-web` - Web Platform
- `component/mad-toolbox` - Developer Utilities

#### Types
- `type/bug` - Bug reports
- `type/feature` - Feature requests
- `type/documentation` - Documentation issues
- `type/performance` - Performance problems
- `type/security` - Security issues

#### Priority
- `priority/critical` - Blocking issues, data loss, security
- `priority/high` - Important features or significant bugs
- `priority/medium` - Standard issues
- `priority/low` - Nice-to-have improvements

#### Platforms
- `platform/desktop` - Desktop applications
- `platform/web` - Web platform
- `platform/all` - Cross-platform issues

## 📈 Issue Lifecycle

1. **🆕 New Issue** - Automatically labeled and triaged
2. **🔍 Triage** - Reviewed by maintainers within 24-48 hours
3. **📋 Backlog** - Approved and prioritized
4. **🚀 In Progress** - Actively being worked on
5. **👀 Review** - Solution implemented, under review
6. **✅ Resolved** - Issue closed and resolved

## 🏷️ Automation

This repository uses GitHub Actions for:
- 🏷️ **Auto-labeling** based on issue content
- 🔍 **Automated triage** for critical issues
- 🧹 **Stale issue management** (30 days inactive)
- 👋 **Welcome messages** for new contributors
- ⏰ **Overdue triage alerts** (48+ hours)
