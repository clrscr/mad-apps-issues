# 🤝 Contributing to Mad Apps Suite

Thank you for your interest in contributing to the Mad Apps Suite! This document provides guidelines for contributing to our central issue tracking repository and the broader Mad Apps ecosystem.

## 🎯 Ways to Contribute

### 📋 Issue Reporting
- Report bugs and issues across all Mad Apps components
- Suggest new features and improvements
- Help improve documentation
- Provide feedback on user experience

### 👨‍💻 Development Contributions
- Fix bugs and implement features
- Improve existing applications
- Create new tools and utilities
- Enhance documentation and guides

### 🌟 Community Contributions
- Help other users in discussions
- Create tutorials and examples
- Share your projects built with Mad Apps
- Participate in feature discussions

## 📋 Issue Guidelines

### Before Creating an Issue

1. **🔍 Search First**: Check if your issue already exists
2. **📖 Read Documentation**: Review existing docs and guides
3. **🆕 Use Latest Version**: Ensure you're using the most recent version
4. **🎯 Choose Right Template**: Select the appropriate issue template

### Issue Templates

Use the appropriate template for your issue type:

- **🐛 [Bug Report](https://github.com/mad/mad-apps-issues/issues/new?template=bug_report.md)** - Something isn't working
- **✨ [Feature Request](https://github.com/mad/mad-apps-issues/issues/new?template=feature_request.md)** - New functionality ideas
- **🌐 [Web Platform Issue](https://github.com/mad/mad-apps-issues/issues/new?template=web_platform_issue.md)** - MadHub web platform problems
- **🖥️ [Desktop App Issue](https://github.com/mad/mad-apps-issues/issues/new?template=desktop_app_issue.md)** - Desktop application problems
- **📚 [Documentation Issue](https://github.com/mad/mad-apps-issues/issues/new?template=documentation_issue.md)** - Documentation improvements

### Writing Quality Issues

#### Good Issue Titles ✅
```
[BUG] maditemmaker crashes when importing Terminal Kingpin files
[FEATURE] Add keyboard shortcuts to theme-editor toolbar
[WEB] madhub-api returns 500 error on large file uploads
[DOCS] Installation guide missing Python 3.12 requirements
```

#### Poor Issue Titles ❌
```
Doesn't work
Bug in app
New feature needed
Fix this
```

#### Essential Information

For **Bug Reports**:
- Clear description of the problem
- Step-by-step reproduction instructions
- Expected vs actual behavior
- Environment details (OS, Python version, app version)
- Screenshots or error messages

For **Feature Requests**:
- Problem statement (what pain point does this solve?)
- Proposed solution description
- User stories and use cases
- Acceptance criteria
- Impact assessment

- `type/bug` - Bug reports
- `type/feature` - New features
- `type/enhancement` - Improvements
- `type/documentation` - Documentation issues
- `type/performance` - Performance problems

## 🔄 Issue Lifecycle

Understanding how issues are processed:

### 1. **Submission** 📝
- Issue created using appropriate template
- Automatic labeling applied based on content
- Welcome message for new contributors

### 2. **Triage** 🔍 (24-48 hours)
- Maintainer reviews and validates issue
- Additional labels applied as needed
- May request more information if needed

### 3. **Planning** 📋
- Confirmed issues added to project boards
- Priority and milestone assignment
- Assignment to appropriate team members

### 4. **Implementation** 🚀
- Development work begins
- Progress updates in issue comments
- Community involvement welcome

### 5. **Review** 👀
- Solution tested and reviewed
- Feedback incorporated
- Final validation

### 6. **Resolution** ✅
- Issue closed with resolution details
- Release notes updated if applicable

## 🤖 Automation

This repository uses several automated systems:

### Auto-Labeling
- Issues automatically labeled based on title and content
- Component detection from checkboxes and keywords
- Priority detection for urgent issues

### Triage Assistance
- Welcome messages for first-time contributors
- Requests for additional information when issues are incomplete
- Overdue triage alerts for maintainers

### Stale Issue Management
- Issues marked stale after 30 days of inactivity
- Automatic closure after 14 additional days
- Exemptions for critical issues and work in progress

## 🔒 Security

### Reporting Security Issues
- **DO NOT** create public issues for security vulnerabilities
- **Email** security@mad-apps.com with details
- **Include** affected components, reproduction steps, and impact assessment
- **Expect** acknowledgment within 24 hours

### Security Best Practices
- Never include passwords, API keys, or sensitive data in issues
- Sanitize logs and error messages before sharing
- Report potential vulnerabilities responsibly

## 🚀 Getting Started

### For New Contributors

1. **Explore the Ecosystem**
   - Browse existing issues to understand common patterns
